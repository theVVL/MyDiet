# MyDiet

Приватный дневник питания: держать дефицит калорий и белок
**без кухонных весов**. Порции — только целые магазинные единицы.

**Параметры:** 83 кг, 180 см, 28 лет; ходьба 10–15 тыс. шагов,
турник и бег 1–2 раза в неделю.
**Норма дня:** 2100–2200 ккал, 160–165 г белка, ~65–75 г жира,
~200–220 г углеводов.

## Единицы измерения (весов нет)

пачка/упаковка 400 г · стакан 250 мл · банка · скуп протеина 30 г ·
порция салата 200 г · кастрюля борща 3,5 л = 8 порций

## Карта репозитория

Читай файлы по мере необходимости, не загружай всё сразу.

- `README.md` — главная страница и история недель. Сверху описание
  проекта, ниже блоки недель по порядку: **новый блок дописывается
  в конец**. Внутри блока строгий порядок: заголовок → таблица →
  продукты → как готовить
- `РАЦИОН.md` — база блюд: 16 блоков с закупкой, готовкой, выходом
  в контейнерах и ккал/белком. Неделя собирается только из этих
  блоков; новое блюдо сначала сюда
- `AGENTS.md` — этот файл
- `.opencode/command/start.md` и `finish.md` — команды `/start`, `/finish`

## Команды

- `/start` — собрать черновик новой недели (см. протокол)
- `/finish` — записать согласованную неделю в `README.md`, коммит и пуш

## Жёсткие правила

- **Цифры не выдумывать.** Ккал и белок в `РАЦИОН.md` — оценка по
  справочным таблицам, помечена «≈»; уточнять по этикеткам купленных
  продуктов и править базу.
- **Покупки = нужно минус остатки.** В `/start` всегда спрашивать,
  что осталось от прошлой недели, и вычитать.
- **Чередование:** один и тот же блок не повторять чаще, чем через
  день; при сборе недели смотреть предыдущие 1–2 недели.
- **Норма белка 160–165 г** — не повышать без согласования с человеком.
- **Медицинских рекомендаций не даём:** симптомы, анализы, лекарства —
  к врачу; здесь только еда и режим.
- **Личные данные:** репозиторий приватный; вес, здоровье и рацион
  никуда больше не выкладывать.
- **Борщ и салаты:** борщ в неделе только по запросу «с борщом»;
  к борщу обязателен белковый довесок (~20 г). Витаминный салат —
  к любому обеду, винегрет — как гарнир, а не салат.
- **README не переписывать** — только добавлять блок недели в конец;
  не трогать чужие недели, кроме исправления явных ошибок по команде.
- Git — только по `/finish` или явной команде («коммить», «пушь»).

## Протокол недели

1. `/start` (воскресенье): прочитай последние 1–2 блока недель
   в `README.md` и `РАЦИОН.md`; задай три вопроса: что осталось
   из прошлых закупок, сколько дней человек дома на неделе,
   нужен ли борщ.
2. Покажи черновик: заголовок недели → таблица пн–вс → продукты
   по отделам (с учётом остатков) → как готовить (вс и ср: основные
   блоки, каша завтрака на 2–3 дня и партия варёных яиц 6–9 шт).
   Файлы не менять, ждать «ок».
3. После «ок» — правь черновик по замечаниям, пока человек
   не скажет `/finish`.
4. `/finish`: запиши блок в конец `README.md`, проверь сумму ккал
   и белка по дням, коммит и пуш.
