Ты собираешь черновик новой недели для MyDiet. Действуй по порядку:

1. Прочитай последние 1–2 блока недель в конце `README.md` (последние
   использованные блюда, чтобы не повторять подряд) и `РАЦИОН.md`.

2. Задай человеку три вопроса (не больше):
   - что осталось из прошлых закупок (мясо/рыба в морозилке, крупы,
     банки, яйца, молочка);
   - сколько дней на неделе он дома (дома ест из тарелки / берёт
     контейнеры с собой);
   - нужен ли борщ на этой неделе.

3. Собери черновик в чате, в таком порядке:
   - заголовок недели (даты пн–вс);
   - таблица: строки — дни, колонки — завтрак / обед / перекус / ужин
     + добор + итог ккал и белка за день; в ячейке — **полное название
     блюда** и ккал/белок, без кодов З1/О2;
   - продукты: по отделам (мясо и рыба / бакалея / заморозка / молочка /
     прочее), в упаковках и штуках, с вычетом остатков;
   - как готовить: воскресенье (на пн–ср) и среда (на чт–вс),
     для каждого захода — блоки и количество контейнеров, плюс каша
     завтрака на 3 дня и партия варёных яиц (6–9 шт).

4. Проверь: каждый день 2100–2200 ккал и 160–165 г белка
   (считая белковый добор), покупки покрывают все блоки без лишних
   упаковок.

5. Файлы не меняй. Жди «ок» или правок; запись в `README.md` — только
   по `/finish`.
