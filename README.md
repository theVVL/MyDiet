# MyDiet

Приватный дневник питания. Цель — держать дефицит и белок без взвешивания еды.

- **Параметры:** 83 кг, 180 см, 28 лет. Ходьба 10–15 тыс. шагов, турник и бег 1–2 раза в неделю.
- **Норма дня:** 2100–2200 ккал, 160–165 г белка.
- **Без весов:** упаковка/пачка 400 г, стакан 250 мл, банка, скуп протеина 30 г, порция салата 200 г.
- **Готовка:** воскресенье — на пн–ср, среда — на чт–вс.
- **Блюда и порции:** [`РАЦИОН.md`](РАЦИОН.md).

## Как устроена неделя

Каждая неделя — отдельный блок, новые добавляются в конец файла.
Внутри блока всегда один порядок: **заголовок недели → таблица → продукты → как готовить**.
